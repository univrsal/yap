## Screen sharing

You can share your screen in calls and voice channels by clicking on the screen
icon in the bottom left corner. The quality and codec can be configured
in the settings (slider icon in the bottom left corner) under screen share.
The quality adapts to whoever is viewing the share, so if a user has a bad
connection the quality is reduced to accommodate for that. Similarly video
codecs are also picked based on the users in the channel because not all
devices support all codecs. If a user joins later on and has trouble viewing
the screen share you can restart it to pick the correct codec.

### Compatibility

Screen sharing is available on all platforms, but only works in browsers by
default. On Linux it can work by default if the correct dependencies are
available and found on the system. If they are not available the yap-video
component has to be installed next to the yap executable.
